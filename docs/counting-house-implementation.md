## Verification so far

The latest `npm test`, after example relocation and evaluation breadth changes, passed 466 tests with zero failures and 20 environment-dependent skips (486 total). Qualification, authority, executor and CLI tests cover changed identities, corrupted bytes, missing evidence, trial completeness, explicit grants, capability ceilings, tenant/action/money scope, expiry/revocation, dead-process lock recovery, exact-proposal consent/review, live booking changes, forbidden tiers, crash before dispatch, crash after commit, partial cancellation and conflicting duplicate refunds. Fourteen executor tests include three concurrent real writer processes, renewed proposals without transferred consent/reviews, voucher settlement, supervisor completion after quote expiry, revoked settlement authority and inconsistent read-back. Casework adds exact-observation linkage, shadow/assist delivery, separate customer access, owned handoff, reopening and overflow-safe cost coverage. HTTP tests exercise both application implementations through the executor, verify credentials cannot forge consent, recover after a server restart and reject a changed evaluator artifact until restart. Learning tests verify blind labels, adjudication, rubric/judge identity, development contamination, gold exposure and separate IntentGauge calibration. Reviewed-regression HTTP tests rerun a known bad policy and both baseline application adapters, linking each new report/qualification to the old case without resolving it automatically.

Chrome verification exercised approval → activation → held assist delivery → answer review → synthetic outbox, and then the separate customer inbox. The execution follow-up prepared a €340 proposal, obtained consent in the customer session, reviewed it in the operator session, injected a crash after cancellation, read back an owned unresolved exception and explicitly authorized the remaining fake refund. The customer's request then showed done. The customer request view had a 390-pixel document width in a 390-pixel viewport; the temporary override was reset. No real payment, external message, real-device or cross-browser coverage is claimed.

The earlier six-module foundation UBS scan had no warnings. The five-file casework/workbench scan reported nine critical and six warning findings. The three-file executor follow-up reported eight critical and two warning findings. All were inspected and classified in `docs/verification/casework-review.md`; neither is reported as a zero-finding scan. Held-out calibration-to-production qualification, actual representative baseline collection, retention, live customer-question adaptation and the remaining evaluation breadth are incomplete.
