# Initial native migration verification (historical)

This records the initial migration before the SDK was removed under ADR 0071. See [native cleanup verification](native-policy-cleanup.md) for the current dependency boundary.

Local verification on 2026-11-05, based on commit `20f60bd` plus the native runtime worktree changes. Host: macOS arm64, Node 26.8.1. This is below the declared Node 26 package minimum; supported-version CI remains separate evidence.

- `npm test`: 468 tests, 448 passed, 20 skipped, zero failed.
- `npm run verify:formal`: all 19 TLA+ configurations returned their expected outcomes, including the deliberately failing mutants; all 54 tied Node tests passed. The append protocol is unchanged, so the models needed no modifications.
- `node scripts/verify-native-install.mjs --legacy`: a temporary production install had zero dependency entries and no SDK. Real CLI processes completed the machining decision, human review, replay, policy listing and JSON/SVG/HTML export; portable JSON and SVG verified. Installing the vendored SDK explicitly in that same deployment then verified the historical JSON fixture. The script deletes its synthetic log directory.
- Native conformance tests compared complete outputs against the original SDK on 40 generated cases for each of the two machining policies, with fresh-source recovery. Separate expected outcomes check arithmetic, dimensions, boolean guards, overflow, division by zero, unsafe integers and governor actions.
- Seeded grammar mutations exercise compile, canonical recovery and evaluation across 1,500 cases. This is a deterministic mutation campaign, not a claim of exhaustive or coverage-guided fuzzing. Boundary tests check byte/value/depth/node limits, cycles, accessors, unsafe keys, unknown fields/operations, references, trace expansion and output expansion.
- The frozen synthetic version 1 receipt verifies. Its regenerated SVG matches a digest captured from the original HEAD renderer; the new legacy renderer was compared directly with that renderer byte for byte. Native version 2 tests reject modified versions, inputs, runtime identity, SVG presentation and reformatted JSON.
- The full proxy driver ran 17 scenarios: 15 passed, the PDF scenario skipped for missing attachment tools, and the Linux bwrap assertion failed on this macOS host. A subsequent run of all 14 non-attachment/non-sandbox scenarios passed with zero failures or skips. These are actual HTTP clients and proxy processes with a mock provider; they are not live model calls. No OpenAI or Anthropic API credentials were present in the environment.
- UBS reviewed the changed paths. The new interpreter, adapter and verification/benchmark scripts had zero critical findings and five warnings: two parses consume JSON emitted by the internal canonical writer, and three benchmark parses intentionally fail on malformed committed fixtures. Broader findings were existing nullish comparisons, cache-signature comparisons misidentified as secret checks, static-page DOM listeners, intentional command output, parser-boundary throws and existing TypeScript assertions. No suppressions or code comments were added.
- `git diff --check` passed. [Performance results](../performance/2026-11-05-policy-runtime/README.md) measure both actual interpreters on identical inputs.

Historical QDL verification requires explicitly installing the legacy SDK in a production deployment. It is retained as a development dependency and optional peer, not copied or silently reimplemented. Native language version 1 covers the actual migrated policies, not every QDL operation. No live model performance or production error-rate claim follows from these checks.
