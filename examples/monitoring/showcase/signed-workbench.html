Export a portable SVG or JSON package, then let the recipient run the independent verifier. The package contains exact QDL source and inputs, so review it first.

ai-audit verify-receipt --input decision.svg
ai-audit verify-attestation --input decision.svg --attestation FILE --public-key KEY
